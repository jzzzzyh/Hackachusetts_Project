================================================================================
TROUBLESHOOTING
================================================================================

Q: Nothing happens after I save a file?
A: Normal! Sync happens silently. Check git log to verify:
   git log --oneline -5

Q: How do I know if sync worked?
A: Check status:
   git status            [Should say "nothing to commit"]
   git log --oneline -1  [Should show your recent commit]

Q: Can I turn off auto-sync?
A: Yes, delete or rename: .kiro/hooks/auto_git_sync.json
   Then restart Kiro

Q: What if there's a merge conflict?
A: Sync script will pause. Fix manually:
   1. git pull to see conflicts
   2. Edit conflicted files
   3. git add [files]
   4. git commit -m "Resolved conflicts"
   5. git push

Q: How do I see sync logs?
A: If using cron:
   tail -f auto_sync.log
   Or check recent commits:
   git log --oneline
