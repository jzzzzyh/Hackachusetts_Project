EXECUTION WORKFLOWS
================================================================================

WORKFLOW 1: Running All Data Loaders
  1. cd scripts/
  2. python3 verify_installation.py
  3. python3 fetch_mbta_bus_shapes.py
  4. python3 decode_mbta_shapes.py
  5. python3 clean_neighborhoods.py
  6. python3 load_trees_data.py
  → Outputs go to: data/

WORKFLOW 2: Adding New Data
  1. Prepare your data file
  2. Copy to: data/your_dataset.csv (or .geojson, .json)
  3. Update scripts if needed
  4. Run processing scripts
  → Scripts read from: data/
  → Outputs saved to: data/

WORKFLOW 3: Building Models
  1. Create new script: scripts/train_model.py
  2. Load data from: data/
  3. Process and train model
  4. Save results to: output/predictions.csv
  5. Save metrics to: output/model_metrics.json

WORKFLOW 4: Running Analysis
  1. Create notebook: notebooks/analysis.ipynb
  2. Load data from: data/
  3. Load results from: output/
  4. Perform analysis and visualization
  → Commit notebook to git
